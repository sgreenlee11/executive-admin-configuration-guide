Executive summary: New Outlook is ready for many EA workflows, but delegation depth still needs validation.

Microsoft's feature matrix for New Outlook was last updated June 5, 2026. The app is generally available, continues to receive feature updates, and is the direction of travel for Outlook on Windows.

01 / HEADLINE
GA

Generally available

New Outlook moved out of preview in August 2024 and is supported for eligible Microsoft 365 customers.

EA

Calendar delegation is available

New Outlook supports assigning calendar delegate access, private-event visibility, category management, and delegate routing choices.

AI

Copilot meeting flows are stronger

EAs can benefit from thread summaries, meeting agenda drafting, meeting prep, and recap access where licensing and permissions allow.

!

Some classic gaps remain

Shared mailbox delegate access is partial; PST, offline, rules, Quick Steps, and legacy add-in patterns should be checked before broad rollout.

Recommended EA framing: position New Outlook as a modern daily-driver candidate for core scheduling, email triage, meeting prep, and Copilot-assisted work, while keeping a readiness checklist for assistants who rely on advanced classic Outlook workflows.

What's new: the updates worth calling out to an experienced EA audience.

This section intentionally skips the familiar "classic versus new" basics and highlights newer capability movement, recent status updates, and changes that affect executive support workflows.

02 / WHAT'S NEW
UpdateGA July 2026Delegation

Events can now be scheduled from a shared or delegate mailbox

Message Center post MC1326502 (Roadmap 561912) lets assistants and delegates organize events on behalf of leaders using a shared or delegated mailbox, so invitations, updates, and notifications send from that mailbox identity. Targeted release ran through June 2026, GA across July 2026.

  • EA angle: the headline change for this audience. Microsoft names executive assistants and chiefs of staff directly - invites finally carry the recognized organizational identity instead of the assistant's personal mailbox.
  • Callout: enabled by default and governed by existing Exchange permissions. Review delegate and shared mailbox permissions, and brief helpdesk on the new sender identity model.
UpdateCopilotGA Aug 2026

Copilot moves into the compose window

Message Center post MC1430542 (Roadmap 564605) puts Copilot side-by-side in the Outlook compose experience so a draft can be created, refined, and edited in real time. Rolling out mid-July to early August 2026 on Outlook web, New Outlook, and mobile; Mac follows, classic Outlook later in 2026.

  • EA angle: this is the core drafting loop for executive correspondence - iterate in place instead of round-tripping between a Copilot pane and the message body.
  • Callout: requires a Microsoft 365 Copilot license. Worth demonstrating live against a real reply-on-behalf-of scenario.
UpdateJuly 2026Calendar

Calendar power-user gaps are starting to close

Ctrl+drag now copies a calendar event, and dragging an .ics file onto the calendar surface previews the invitation before it is accepted. Shared calendars assigned by an administrator also appear automatically without a manual add step.

  • EA angle: copy/paste of events was one of the loudest gaps for experienced calendar managers. This is the item to demo to skeptical power users.
  • Callout: Schedule View, multi-select, and conditional formatting are still outstanding - keep them on the scorecard.
UpdateRetiringMeetings

Meeting Insights is being retired

Message Center post MC1430531 retires Meeting Insights - the panel surfacing related emails and files inside meeting details - beginning mid-August 2026 and completing early September 2026. Copilot-licensed users move to Copilot meeting preparation instead.

  • EA angle: assistants who build pre-reads from Meeting Insights need the Copilot prep equivalent shown to them before the panel disappears.
  • Callout: affects Outlook web, New Outlook, mobile, Mac, and Teams. Non-Copilot users lose the capability without a direct replacement.
UpdateRetiringMobile

Send Availability is disappearing from Outlook mobile

Message Center post MC1393802 removed the Send Availability option from the Outlook mobile compose experience between mid-July and late July 2026. Users share availability by referencing the calendar manually instead.

  • EA angle: a genuine regression for assistants coordinating times from a phone between meetings or while travelling.
  • Callout: flag it explicitly so it is not reported to the helpdesk as a bug. Calendar functionality itself is unchanged.
Recently updatedShared mailbox

Shared mailbox archive is now available

The New Outlook comparison matrix lists shared mailbox archive as available, with a March 2026 status update.

  • EA angle: better support for assistants who need historical lookup in executive or team-managed mailboxes.
  • Callout: pair this with a search/archive validation exercise for high-volume executive offices.
Recently updatedDelegation

Shared mailbox delegate access moved, but is still partial

Shared mailbox delegate access is marked partially available with an April 2026 status update and roadmap tracking.

  • EA angle: do not assume every shared mailbox or executive support pod workflow is fully covered yet.
  • Callout: test Send As, Send on Behalf, category use, and folder access with real assistants.
Newer behaviorMeetings

Follow meetings changes the "I need awareness" pattern

Follow lets an attendee show the time as free while still signaling interest in recording, transcript, and follow-up.

  • EA angle: useful when an executive should not attend but wants the assistant or organizer to preserve meeting artifacts.
  • Callout: organizers in classic Outlook may see Follow as tentative.
AvailableMeeting artifacts

Meeting recap is now a calendar workflow

New Outlook surfaces supported Teams meeting recap links directly from the calendar event, including files, transcript, and recording.

  • EA angle: assistants can retrieve post-meeting artifacts from the calendar instead of hunting across Teams chats and files.
  • Callout: access remains governed by each artifact's original permissions.
CopilotNewer flow

Schedule with Copilot turns email threads into meeting drafts

In New Outlook, Copilot can analyze an email thread, draft the meeting title and agenda, add thread participants, and attach the source thread.

  • EA angle: reduces manual effort when converting long approval or planning threads into a decision meeting.
  • Callout: requires Microsoft 365 Copilot work licensing and sufficient thread context.
CopilotNewer flow

Meeting prep now surfaces context inside the event

Copilot can prepare users for meetings by summarizing relevant context, tasks, documents, and resources from the meeting event form.

  • EA angle: supports faster executive briefing prep when the assistant has access to the relevant meeting content.
  • Callout: tenant Meeting Insights settings and user permissions affect the experience.
Recently updatedMail files

.msg support and Quick Parts are listed as available

The matrix lists .msg support and Quick Parts as available with April 2026 status updates; .oft support remains partial.

  • EA angle: helpful for saved executive messages, recurring language blocks, and reusable response content.
  • Callout: test any existing template-heavy workflows that depend on OFT files.
CopilotMay rollout

Copilot account selector reduces multi-account confusion

When more than one Copilot-enabled account is added to New Outlook, the Copilot side pane in Calendar includes an account dropdown.

  • EA angle: helps assistants and multi-account users confirm which account Copilot is acting on.
  • Callout: include this in validation for anyone juggling multiple work identities or delegated contexts.
UpdatedOffline

Offline support continues to improve

Microsoft notes support for adding attachments while offline, a 30-day offline mail sync window, offline search folders, and undo send while offline.

  • EA angle: better resilience for travel, stores, facilities, and variable connectivity.
  • Callout: still test real travel/offline scenarios before removing classic Outlook fallback.
Coming / changedCalendar

Calendar power-user items are still moving

Schedule View, multi-select calendar events, copy/cut/paste events, conditional formatting, and teammate calendar surfacing are still listed as upcoming.

  • EA angle: this is where experienced calendar managers may feel the most friction.
  • Callout: keep these items on the pilot scorecard, not buried in appendix material.
AvailableTriage

Modern triage patterns are now part of the pitch

Pin, snooze, sweep, schedule send, reactions, category favorites, and drag-and-drop file improvements are available in New Outlook.

  • EA angle: these are the practical wins to demonstrate live, especially for high-volume executive inboxes.
  • Callout: show how these replace daily workarounds rather than explaining them as "new features."
RoadmapDelegation

Mail delegate permission management is on the roadmap

Roadmap item 417063 says users will be able to grant mailbox and folder delegate access from the New Outlook app, planned for July 2026.

  • EA angle: could simplify setup conversations between executives, assistants, and IT.
  • Callout: until available, keep current Exchange/Outlook delegate setup guidance in the rollout plan.
Presenter cue: treat this slide as the "why should I care now?" moment. The audience already knows many gaps; lead with the movements that change their readiness conversation.

Migration roadmap: opt-in today, opt-out and cutover later with notice.

Microsoft describes three progressive stages for New Outlook migration: opt-in, opt-out, and cutover. Managed Enterprise plans receive at least 12 months notice before opt-out and cutover stages in production rings.

03 / ROADMAP

Stage 1: Opt-in

Users can try New Outlook with the toggle, switch back if needed, and in some cases run classic and New Outlook side-by-side for comparison.

General availability

New Outlook became generally available in August 2024, with feature development continuing after GA.

Stage 2: Opt-out

New Outlook becomes on by default after notice; users can still revert to classic Outlook while the opt-out stage applies.

Stage 3: Cutover

Users can no longer switch back. Existing classic Outlook installations remain supported until at least 2029.

EA impact Adoption planning

What EAs should hear

  • No surprise cliff: enterprise tenants should receive advance notice before disruptive stage changes.
  • Try with guardrails: EAs can pilot New Outlook while keeping classic Outlook available for critical edge workflows.
  • Feedback matters: Microsoft points users to Help > Give Feedback to influence feature prioritization.
  • Plan around role complexity: assistants with high-volume delegation, shared mailboxes, custom forms, macros, or COM add-ins need targeted validation.
Presenter cue: emphasize that readiness is workflow-based, not persona-based. A general employee may be ready before an EA who manages multiple executives and shared resources.

EA workflow updates: where New Outlook helps day-to-day execution.

The most relevant changes for executive assistants are in calendar delegation, meeting response handling, meeting recap, mailbox organization, and rapid task capture.

04 / EA WORKFLOWS
AvailableCalendar

Delegate calendar access

New Outlook supports editor and delegate calendar access for work or school accounts in Microsoft 365 / Exchange Online.

  • Delegates can schedule and respond to meetings on behalf of the executive.
  • Owners can allow private-event visibility and category management.
  • Meeting request routing can be delegate only, delegate plus copy, or both owner and delegate.
AvailableMeetings

Follow a meeting

Attendees who cannot join can choose Follow, signaling they want recordings, transcripts, and follow-up while showing the time as free.

  • Useful when an executive wants awareness without blocking the calendar.
  • Organizers receive a visible Follow response and are reminded to record.
  • Classic Outlook organizers may see the response as tentative.
AvailableTeams + Outlook

Meeting recap in calendar

Past Teams meetings can show links to files, transcript, and recording directly from the Outlook calendar event.

  • Helps EAs find outcomes without searching Teams manually.
  • Does not store content in Outlook; it links to original locations.
  • Each meeting asset retains its own access permissions.
AvailableProductivity

My Day with Calendar and To Do

My Day keeps upcoming events and tasks visible from Mail, Calendar, and People, including quick task and event creation.

  • Drag an email into To Do to create a task.
  • Join Teams meetings without switching to full calendar view.
  • Show additional calendars in the My Day pane.
AvailableMail

Modern message management

New Outlook includes pin, snooze, sweep, schedule send, reactions, and category favorites that can streamline executive mailbox triage.

  • Pin high-priority asks while processing mail.
  • Snooze messages until a decision window.
  • Use Sweep for recurring low-value mail.
ValidateShared mailbox

Shared mailbox improvements

Shared mailboxes and shared folders are available. Shared mailbox archive is listed as available as of March 2026, while shared mailbox delegate access is partially available as of April 2026.

  • Test executive/team shared mailbox scenarios before switching primary workstations.
  • Confirm Send As / Send on Behalf behavior with IT where required.

Copilot in New Outlook: the biggest EA productivity accelerators.

Copilot features depend on licensing and permissions. For EAs, the value is strongest when they already have access to the relevant mailbox, thread, calendar event, file, transcript, or meeting content.

05 / COPILOT
UpdateCopilotNotebooks

Pull Outlook emails into Copilot Notebooks

Message Center post MC1392569 (Roadmap 564910) lets Outlook emails be added as references in Copilot Notebooks alongside files and links, with GA rolling out mid-July through late July 2026.

  • EA use: build a durable notebook per initiative that includes the actual email decisions, then generate briefs, summaries, and decks grounded in that thread history.
  • Watchout: notebook references inherit source permissions - confirm what a shared notebook exposes before circulating it.
UpdateCopilotClassic Outlook

Copilot settings reach classic Outlook for Windows

Message Center post MC1358831 (Roadmap 561491) adds Copilot settings to the File menu in classic Outlook for Windows, including the option to turn Copilot on or off. GA ran early July to late July 2026.

  • EA use: useful for the population still on classic Outlook while the migration runs - settings now sit where the feature is used.
  • Admin note: this does not change Copilot licensing, eligibility, or existing admin controls.
CopilotAvailable

Summarize email threads and attachments

Copilot can summarize email conversations and cite source messages. In New Outlook, users can also summarize supported Word, PowerPoint, and PDF attachments from the email.

  • EA use: create a quick brief from long scheduling, travel, or approval threads.
  • Watchout: Copilot only summarizes content the user can access.
CopilotAvailable

Schedule with Copilot from an email thread

New Outlook can analyze a thread, create a meeting invitation, add the people on the thread, draft a title and agenda, and attach the email thread.

  • EA use: convert a messy back-and-forth into a structured meeting draft.
  • Watchout: confidential or low-context discussions may not generate agenda content.
CopilotAvailable

Prepare for your meeting

Copilot can surface meeting context, related tasks, documents, and insights in Outlook meeting details, with deeper chat prompts available.

  • EA use: assemble pre-reads or last-minute context for executives.
  • Admin note: Microsoft documents a Meeting Insights tenant setting in the Microsoft 365 admin center.
CopilotAvailable

Draft and coach email

Copilot can draft messages, summarize, coach tone, and help refine executive communications inside Outlook.

  • EA use: move from rough executive intent to polished draft faster.
  • Governance: verify appropriate delegation and mailbox access before relying on assistant-driven Copilot flows.
CopilotNewer flow

Add Outlook email context into Copilot Chat

Implicit Grounding in Outlook lets users add selected emails or thread text directly into Microsoft 365 Copilot Chat prompts.

  • EA use: ground escalation briefs, meeting prep, and draft replies in the exact email context being reviewed.
  • Watchout: still verify the selected source context and citations before sending executive communications.
CopilotMulti-account

Confirm the active Copilot account

The Outlook Copilot side pane account selector helps users switch between Copilot-enabled accounts without relying only on Outlook's broader account context.

  • EA use: reduce mistakes when switching between personal work, project, and delegated executive contexts.
  • Admin note: include account-context screenshots in training for multi-account users.

Watchouts: the classic Outlook workflows most likely to affect executive assistants.

These are the areas to ask about before telling an EA that New Outlook is their new default.

07 / WATCHOUTS
Not supported

COM add-ins, VBA, MAPI/OOM, custom forms

New Outlook uses a modern web add-in model and does not support several classic Outlook extension patterns.

  • Ask EAs which add-ins or macros they rely on daily.
  • Check vendor availability for web add-ins.
Partial

Rules, Quick Steps, offline, PST

Several classic productivity and resilience features are partially available rather than fully equivalent.

  • Capture top automation flows.
  • Confirm offline behavior during travel or in stores/facilities with variable connectivity.
Upcoming / investigating

Calendar power-user features

Schedule View, multi-select calendar events, copy/cut/paste calendar events, and conditional formatting are marked upcoming; custom holidays are under investigation.

  • Ask EAs how they manipulate complex calendars today.
  • Keep classic Outlook available if gaps block critical scheduling.
Not supported

Network shares and SharePoint calendar sync

Accessing files on network shares and classic SharePoint calendar sync are listed as not supported.

  • Move repeat workflows to supported cloud file links or group calendars where appropriate.
Not supported

Voting buttons

Voting buttons are listed as not supported in New Outlook.

  • Use Forms, approvals, or other survey patterns for executive polling.
Partial

Public folders and search folders

Both are partially available, which may matter for legacy team processes.

  • Check if executive offices use public folders for shared reference or routing.

Admin controls: how IT can pace New Outlook adoption.

Microsoft documents controls for toggles, installation, automatic migration, mailbox access, and conditional access. These controls matter when EAs need a phased migration.

08 / ADMIN
Admin control

Control access and install paths

  • Hide the "Try the new Outlook" toggle using Cloud Policy in the Microsoft 365 Apps admin center.
  • Remove or block New Outlook app installation patterns where the organization is not ready.
  • Block Microsoft Store acquisition if required by policy.
  • Use Exchange mailbox policy to block work/school mailbox access as a final app-access control.
Admin control

Control migration timing

  • Admins can opt out of automatic migration by policy.
  • New Outlook automatic migration settings can be controlled through registry, Group Policy, or Cloud Policy.
  • Conditional Access and OWA mailbox policies can enforce device, MFA, and attachment-related controls.
Copilot support

Prepare support for Copilot settings in classic Outlook

  • Copilot settings are being added under the File menu in classic Outlook for Windows, with preview in June and GA planned for July 2026.
  • Support teams should know where users can toggle Copilot and how that differs from tenant licensing or admin controls.
Adoption control

Use targeted Copilot adoption messages

  • Organizational Messages now supports email delivery and usage-based targeting for Copilot adoption segments.
  • Use this for targeted nudges to inactive Copilot users, pilot cohorts, or EA groups after New Outlook training.
EA rollout recommendation: create an EA pilot ring with named executive/delegate pairs, shared mailbox scenarios, Copilot license coverage, required add-ins, and calendar power-user workflows. Promote only the scenarios that pass real-world validation.
